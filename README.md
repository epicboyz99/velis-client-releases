# Velis Client

Official downloads for **Velis Client**, a fast, clean Minecraft launcher.

## Download
Go to the [Releases](https://github.com/epicboyz99/velis-client-releases/releases/latest) page and download `VelisClient-WebSetup.exe` (Windows 10/11).

## Notes
- Free to use.
- Windows may show an "unknown publisher" warning because the installer is not code-signed yet. Click "More info" -> "Run anyway".
- Velis Client is not affiliated with, endorsed by, or associated with Mojang Studios, Microsoft, or Minecraft.
